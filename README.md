# dotfiles

Personal configuration files.

## Install

```bash
./install.sh
brew bundle  # install packages
```

## Contents

- `Brewfile` - Homebrew packages, casks, and VS Code extensions
- `git/` - Git config (public) + template for private local config
- `ghostty/` - [Ghostty](https://ghostty.org) terminal config
- `mise/` - [mise](https://mise.jdx.dev) tool versions
- `nvim/` - Neovim config (coc.nvim, denite, sonokai theme)
- `zsh/` - Zsh config (oh-my-zsh + powerlevel10k)
